累計消費分鐘發放

由管理員直接增加會員累計消費分鐘，系統會自動重算會員等級、保存發放原因與稽核紀錄，並嘗試透過 LINE 官方帳號推播。

發放分鐘

只能對目前有效的會員發放。發放原因會同時保存於系統、顯示在會員端，並寫入 LINE 推播訊息。

發放動作會由 Server-side 再次驗證管理權限。LINE Channel Access Token 僅從 GAS Script Properties 讀取，不會傳到瀏覽器。
